# Дополнение для бэкендера: итоговая стоимость оффера

`backend-offer-totals.patch` — переносимый `git format-patch` коммита `8c96e16`, подготовленного поверх `GatheredSatyr53/probiinik@a0de76b`.

Git-атрибуты сохраняют для `.patch` переводы строк LF и намеренные пробелы контекста unified diff. Это настройка хранения патча, конфигурация приложения не меняется.

## Назначение

Фронтенд показывает общую выплату и переплату до принятия предложения. В исходном API v2 этих полей в `offer` нет. Патч добавляет nullable `totalPayment` и `totalInterest` в `OfferDto` и OpenAPI.

Для WorkingCapital, Express, Investment суммы рассчитывает `LoanMath.Schedule` по фактическим параметрам оффера с учётом округления последнего платежа. Для Overdraft и CreditLine новые поля равны `null`. Формула preview/скоринга, существующие условия заявок и даты графика не меняются. Миграций и новых переменных окружения нет.

## Применение

В чистом checkout бэкенда обновите `main`, затем создайте рабочую ветку по правилам команды и примените патч:

```powershell
git am "C:\Users\si_kl\WebstormProjects\alfa\integration\backend-offer-totals.patch"
docker compose up -d --build
```

Если папки репозиториев отличаются, укажите свой путь к скачанному патчу. Перед применением можно проверить совместимость командой `git apply --check <путь-к-патчу>`. При конфликте не применяйте патч принудительно: рассмотрите изменения пяти файлов относительно своей версии API. `git am --abort` отменяет незавершённое применение патча.

## Проверки

На подготовленной версии прошли 243 unit-теста и 36 интеграционных тестов бэкенда, без пропусков. Интеграционные тесты использовали отдельные автоматически создаваемые базы PostgreSQL. После упрощения тестового кода отдельно повторены два `OfferMappingTests` — оба прошли.

Контрольный оффер до принятия: сумма 1 500 000 ₽, 12 месяцев, 19,5 %, платёж 138 593,06 ₽. API возвращает `totalPayment = 1663116.74`, `totalInterest = 163116.74`; умножение округлённого платежа на срок дало бы другой результат.

Патч проверен на соответствие локальному коммиту и на применение поверх базового `a0de76b`. Через браузер проверена заявка AC-000009: preview v2, перерасчёт срока, подача, реальные суммы оффера до принятия, договор, неверный код, подстановка полученного demoCode, подпись, выдача и повторное открытие.

В upstream репозиторий бэкенда изменения не отправлены: у `exsyyy` нет прав записи. Создание отдельного форка отклонено автоматической проверкой, поэтому код передаётся этим патчем. Фронтенд совместим с исходным API: если суммы не пришли, он сообщает об их отсутствии и не рассчитывает их самостоятельно.
